# scripts/burst-state-surface.txt — PRD-build-burst-state-keyed-by-server-v2
# requirement 1/10. One line per name mechanically discoverable under
# $STATE_DIR (state/burst-lane/) in scripts/burst-lane.sh, classified
# per-box | lane-wide | structural. Format: "<name> <class>  # <note>",
# whitespace-separated, first token is the name — checked by
# scripts/burst-state-tripwire.sh (run from burst-lane-selftest.sh's
# tripwire block), which fails the moment a new $STATE_DIR/<name> or
# $BOX_STATE_DIR/<name> literal lands in burst-lane.sh without a matching
# line here (AC13). Do not delete a line when a name stops being used —
# an extra, unused entry is harmless; a missing one fails the build.
#
# "per-box" = lives under state/burst-lane/boxes/<server_id>/, reached via
# $BOX_STATE_DIR (== $STATE_DIR/current, requirement 1's box_path()).
# "lane-wide" = stays at state/burst-lane/<name> top-level, reached via
# $STATE_DIR directly — never routed through box_path()/$BOX_STATE_DIR.
# "structural" = not itself a state file/dir with owner semantics; part of
# the layout mechanism.
